TripBalancing currency-display-only itinerary fix
Date: 2026-08-18

Changes:
1. Display currency no longer participates in itinerary cache identity.
2. Recommended/Ideal Budget mode uses a currency-neutral AI prompt.
3. Fixed budgets are normalized to a canonical INR economic value before they affect cache/prompt identity.
4. Equivalent AED/INR/USD/EUR/GBP/JPY requests now reuse the same itinerary content.
5. The user's selected currency remains authoritative only when reconcileItineraryBudget formats prices for the response/PDF.
6. Cache identity now includes traveler type, style, purpose, weather, interests, planning mode and revisit preferences, so genuinely different trips do not collide.
7. Existing exact-trip-duration enforcement is preserved.

Expected test:
Generate Dubai -> Baku with identical dates, 4 days, 2 travelers, Budget, Recommended Ideal Budget.
Generate once in INR and once in AED. Hotels/attractions/activities/route should be identical; only monetary display values should differ by FX conversion.
