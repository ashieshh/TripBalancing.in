TripBalancing Step 6 - Final form UX fixes (2026-08-25)

Changes limited to the 3 reported issues:

1) Budget currency default
- The Maximum Total Trip Budget currency now defaults from the signed-in user's saved country.
- India -> INR
- UAE -> AED
- UK -> GBP
- Japan -> JPY
- Euro-area countries -> EUR
- Other countries -> USD
- The currency dropdown remains available so the traveler can choose another supported currency afterwards.
- The same budgetCurrency state is used in fixed-budget and AI-recommended-budget mode.

2) Number of travelers
- Removed the browser-native editable number input/spinner behavior that caused inconsistent values in the video.
- Traveler count is now controlled only by the existing - and + buttons.
- Minimum 1, maximum 50.
- No visual redesign.

3) From / To location keyboard navigation
- Arrow Down / Arrow Up navigate location suggestions.
- Enter selects the highlighted suggestion.
- Escape closes the suggestions.
- Mouse selection still works exactly as before.
- Added standard combobox/listbox accessibility metadata and highlighted keyboard selection.
